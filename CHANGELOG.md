# Changelog

## 1.0.0 (2026-10-28)

- First public release, targeting Resource Hero v16.2 and the Resource Hero MCP extension 0.1
  (limited release).
- Two plugins in the `resource-hero` marketplace: `rh-user` (log, review and chart your own
  time, run timers, check your forecast and capacity, request time off, and a ready-made live
  time dashboard) and `rh-connect` (admin setup and the Claude Code connection to your org's
  Resource Hero User MCP server, 16 tools).
- Admin and user guides for Claude on the web and desktop and for Claude Code.
- Each `v*` release attaches the plugins as zips, for claude.ai organizations that upload
  plugins.
